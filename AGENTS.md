# ContextMemory Agent Guide

## Project
ContextMemory is a persistent memory and context-optimization layer for modern AI agents.

## Core principles

- Prefer simple, inspectable systems.
- Do not overengineer early prototypes.
- Keep architecture decisions documented.
- Verify claims with tests or evidence.
- Never expose API keys or secrets.
- Read relevant existing code before modifying it.

## Workflow

THINK TEAM:
Research -> architecture -> plan -> handoff.

FORGE TEAM:
Inspect task -> implement -> test -> verify -> report.

## Collaboration

Use the repository as the source of truth.

Important findings should be written to:
- docs/research/
- docs/architecture/
- reports/

Active implementation work belongs in:
- tasks/active/

Completed work belongs in:
- tasks/completed/

## Testing

Never claim something works without running relevant verification.
